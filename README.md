# Barricade 기록 대국

AI와 바리케이드(barricade.gg 규칙, 9×9)를 한 판 두면, 모든 수와 요인 값이 팀 공용 기록(Supabase)에 자동으로 저장되는 웹 앱입니다.
조원 누구나 링크로 접속해 두면 되고, "전체 기록 엑셀 받기" 버튼으로 모든 조원의 기록을 엑셀 파일 하나로 내려받습니다.

- 접속 주소: https://jwudiase.github.io/barricade-record/
- 설치할 것 없음. PC와 휴대폰 브라우저 모두 동작합니다.
- 같은 브라우저에서 탭 두 개로 동시에 두지 마세요. 나중에 연 탭만 진행되고, 먼저 연 탭은 멈춥니다.
- Supabase 무료 요금제는 1주일 동안 사용이 거의 없으면 일시정지됩니다. 기록은 남아 있으니 대시보드에서 다시 켜면 됩니다.

## 구성
| 파일 | 역할 |
|---|---|
| `index.html`, `app.js` | 화면, 대국 진행, 매 수 기록 |
| `engine.js`, `zobrist.js` | 게임 규칙·알파베타 AI·요인 계산. 파이썬 `barricade_ai/engine.py`, `search.py`, `similar_ai/features/feat.py`를 그대로 옮긴 것 |
| `ai-worker.js` | AI 계산을 화면과 따로 돌리는 웹 워커 (AI 수용 1개, 내 차례 추천 계산용 1개) |
| `record.js` | 한 수의 기록 줄 만들기 (6개 요인 포함 나 기준 값 15개, 변화량, 행동 종류, 국면) |
| `store.js` | Supabase 저장. 전송 전 브라우저에 먼저 보관하고, 끊기면 다시 보냄 |
| `excel.js`, `exceljs.min.js` | 엑셀 파일 만들기 (ExcelJS, MIT 라이선스). 후반 그래프 시트의 구간 승률·가중 회귀 계산 포함 |
| `xlcharts.js`, `jszip.min.js` | 엑셀에 기본 차트(분산형 그래프)를 넣기 (JSZip, MIT 라이선스) |
| `config.js` | Supabase 주소와 공개 키 |
| `schema.sql` | Supabase 표·보안 규칙 (읽기·추가만 허용, 수정·삭제 불가) |

## 검증
- 파이썬 원본과 대조: 무작위 국면 2,663개에서 합법 수, 해시, 요인 15개, 행동 종류, 후보 수 정렬, 평가값이 모두 일치.
- 알파베타: 깊이 1–6 국면 344건, 그리고 깊이 3–10끼리 끝까지 둔 대국 9판(AI 수 400여 개)에서 고른 수·점수·탐색 노드 수까지 모두 일치.

## 국면과 후반 그래프 (v1.1)
- 국면: 두 사람이 쓴 벽의 합계로 나눕니다. 0~5개 초반, 6~13개 중반, 14개 이상이거나 한쪽 벽이 다 떨어지면 후반.
- 6개 요인(팀 독립변인): 우회율, 벽 점유율, 경로 취약도, 공격 잠재력, 경로 폭, 중앙 이탈도.
- 엑셀의 "후반 그래프" 시트: 끝까지 둔 판의 후반 장면만, 0.1 구간(중앙 이탈도는 5단계)별로 판마다 한 번씩만 세어 승률을 내고, 10판 이상인 구간으로 가중 회귀선을 그립니다.

## 기록 항목
엑셀의 "요인 설명" 시트에 각 항목의 정의가 있습니다. 모든 값은 플레이한 사람 기준이고, 행동 종류만 그 수를 둔 쪽 기준입니다.
